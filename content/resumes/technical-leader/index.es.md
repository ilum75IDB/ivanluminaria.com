## Perfil Profesional

Technical Leader con casi 30 años de experiencia en bases de datos (Oracle, PostgreSQL, MySQL) y Data Warehouse enterprise mission-critical.

Acompaño a CIOs, CTOs e IT Directors cuando un sistema de datos se ralentiza, se detiene o debe cambiar de dirección. Cuando la causa atraviesa varios niveles — aplicación, SQL, base de datos, sistema operativo, almacenamiento, red, arquitectura de datos — leo la cadena completa y explico cada paso a quienes deben decidir.

Tres pilares técnicos: **database administration**, **performance y troubleshooting**, **Data Warehouse y data architecture**. Dos capacidades que los mantienen unidos: **coordinación técnica de los equipos** y **transferencia de competencias**, para que cada intervención deje sistemas más estables y personas más autónomas.

## Áreas de intervención

- **Health Check de las bases de datos** — evaluación estructurada de performance, fiabilidad, capacidad y riesgos latentes en Oracle, PostgreSQL y MySQL, con un informe de evidencias y un roadmap de prioridades.
- **Post-Incident Root Cause Analysis** — reconstrucción del incidente sobre datos reales (AWR, ADDM, ASH, wait events, logs aplicativos e infraestructurales), separando causas, consecuencias y simples correlaciones, con un plan de remediación verificable.
- **Technical leadership continuo** — evaluaciones técnicas independientes, coordinación entre desarrollo, DBA e infraestructura, gobernanza de las decisiones arquitectónicas.
- **Data Warehouse design** — diseño end-to-end de DWH y pipelines ETL/ELT sobre Oracle y PostgreSQL, con atención al modelado, tiempos de carga y sostenibilidad en el tiempo.

## Competencias Clave

### Bases de datos de misión crítica

- Oracle Database 8i → 21c, Oracle Exadata, Oracle RAC, Oracle Data Guard, Oracle Autonomous Database
- PostgreSQL 14+ (query optimization, partitioning, `pg_stat_statements`, PgBouncer, replicación lógica, tuning de autovacuum)
- MySQL enterprise (administración, replicación, optimización InnoDB)
- Alta disponibilidad y disaster recovery (Data Guard, RMAN, Flashback, procedimientos de switchover/failover)
- Seguridad (Oracle TDE, gestión de privilegios, auditing), Storage Management (ASM, tablespaces)
- Instalación, patching (PSU/CPU/RU), upgrades, migraciones cross-platform

### Performance tuning cross-layer

- Análisis y diagnóstico: AWR, ADDM, ASH, Statspack, SQL Trace, TKPROF, Explain Plan
- SQL tuning: consultas complejas, hints, SQL Profiles, SQL Plan Management
- Instance tuning: memoria (SGA/PGA), parámetros de inicialización, análisis de wait events
- Diseño para performance: indexación (B-tree, Bitmap, Function-based), partitioning (Range, List, Hash, Composite), compression
- Lectura por niveles: aplicación → SQL → base de datos → sistema operativo → almacenamiento → red → arquitectura de datos

### Data Warehouse y Data Architecture

- Metodologías Kimball e Inmon: Star Schema, Snowflake, Slowly Changing Dimensions, Bus Matrix
- ETL/ELT con PL/SQL y Unix Shell scripting, Oracle Data Integrator, Oracle Warehouse Builder (proyectos legacy)
- Business Intelligence: Oracle Analytics Cloud (Semantic Model Designer, dashboards, informes)
- Integración de fuentes heterogéneas (Oracle, SQL Server, archivos, sistemas enterprise)

### Cloud

- Oracle Cloud Infrastructure (Compute, Storage, Networking, Database Services, Autonomous Database)
- AWS Aurora PostgreSQL, entornos Microsoft Azure Database

### Liderazgo técnico y coordinación

- Coordinación de equipos distribuidos de 3 a 7 personas, en contextos multiculturales y full remote
- Agile y Scrum (sprint planning, daily stand-up, retrospective, backlog refinement), con formación certificada
- Cerca de 10 proyectos gestionados con presupuestos entre €100K y €500K, con un sólido track record de entrega en plazos
- Herramientas: Jira, Microsoft Project, Git/GitHub

### Formación y mentoring

- Trainer en Oracle Italia (2000-2001): SQL, Advanced SQL, PL/SQL, Oracle DBA, Performance & Tuning, Discoverer, Forms, Reports
- Onboarding y mentoring de desarrolladores junior y consultores
