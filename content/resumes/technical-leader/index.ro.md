## Profil Profesional

Technical Leader cu aproape 30 de ani de experienta pe baze de date mission-critical Oracle, PostgreSQL si MySQL si pe Data Warehouse enterprise.

Sunt alaturi de CIO, CTO si IT Directori atunci cand un sistem de date incetineste, se opreste sau trebuie sa schimbe directia. Cand cauza traverseaza mai multe niveluri — aplicatie, SQL, baza de date, sistem de operare, stocare, retea, arhitectura de date — citesc lantul complet si explic fiecare pas celor care trebuie sa decida.

Trei piloni tehnici: **database administration**, **performance si troubleshooting**, **Data Warehouse si data architecture**. Doua capacitati care ii tin impreuna: **coordonarea tehnica a echipelor** si **transferul de competente**, pentru ca fiecare interventie sa lase in urma sisteme mai stabile si oameni mai autonomi.

## Arii de interventie

- **Health Check al bazelor de date** — evaluare structurata a performance, fiabilitate, capacitate si riscuri latente pe Oracle, PostgreSQL si MySQL, cu un raport de evidente si un roadmap de prioritati.
- **Post-Incident Root Cause Analysis** — reconstructia incidentului pe date reale (AWR, ADDM, ASH, wait events, log-uri aplicative si de infrastructura), separand cauze, consecinte si simple corelatii, cu un plan de remediere verificabil.
- **Technical leadership continuu** — evaluari tehnice independente, coordonare intre dezvoltare, DBA si infrastructura, guvernarea deciziilor arhitecturale.
- **Data Warehouse design** — proiectare end-to-end de DWH si pipeline-uri ETL/ELT pe Oracle si PostgreSQL, cu atentie la modelare, timpi de incarcare si sustenabilitate in timp.

## Competente Cheie

### Baze de date mission-critical

- Oracle Database 8i → 21c, Oracle Exadata, Oracle RAC, Oracle Data Guard, Oracle Autonomous Database
- PostgreSQL 14+ (query optimization, partitioning, `pg_stat_statements`, PgBouncer, replicare logica, tuning autovacuum)
- MySQL enterprise (administrare, replicare, optimizare InnoDB)
- Inalta disponibilitate si disaster recovery (Data Guard, RMAN, Flashback, proceduri de switchover/failover)
- Securitate (Oracle TDE, gestionare privilegii, auditing), Storage Management (ASM, tablespaces)
- Instalare, patching (PSU/CPU/RU), upgrade-uri, migrari cross-platform

### Performance tuning cross-layer

- Analiza si diagnosticare: AWR, ADDM, ASH, Statspack, SQL Trace, TKPROF, Explain Plan
- SQL tuning: interogari complexe, hints, SQL Profiles, SQL Plan Management
- Instance tuning: memorie (SGA/PGA), parametri de initializare, analiza wait events
- Design pentru performance: indexare (B-tree, Bitmap, Function-based), partitioning (Range, List, Hash, Composite), compression
- Citire pe niveluri: aplicatie → SQL → baza de date → sistem de operare → stocare → retea → arhitectura de date

### Data Warehouse si Data Architecture

- Metodologiile Kimball si Inmon: Star Schema, Snowflake, Slowly Changing Dimensions, Bus Matrix
- ETL/ELT cu PL/SQL si Unix Shell scripting, Oracle Data Integrator, Oracle Warehouse Builder (proiecte legacy)
- Business Intelligence: Oracle Analytics Cloud (Semantic Model Designer, dashboard-uri, rapoarte)
- Integrare de surse eterogene (Oracle, SQL Server, fisiere, sisteme enterprise)

### Cloud

- Oracle Cloud Infrastructure (Compute, Storage, Networking, Database Services, Autonomous Database)
- AWS Aurora PostgreSQL, medii Microsoft Azure Database

### Leadership tehnic si coordonare

- Coordonare a echipelor distribuite de la 3 la 7 persoane, in contexte multiculturale si full remote
- Agile si Scrum (sprint planning, daily stand-up, retrospective, backlog refinement), cu formare certificata
- Aproximativ 10 proiecte gestionate cu bugete intre €100K si €500K, cu un track record solid de livrare la timp
- Instrumente: Jira, Microsoft Project, Git/GitHub

### Formare si mentoring

- Onboarding si mentoring de dezvoltatori juniori si consultanti
