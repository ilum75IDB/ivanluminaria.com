In Oracle's release model, each development branch produces several intermediate releases and closes with a **Terminal Release**: the final version of the branch, which Oracle designates for its longest support lifecycle. The term does not imply end-of-life — quite the opposite: it marks the most stable and longest-supported release in the group.

## How it works

Oracle organizes its database versions into progressive branch releases (e.g., 12.1, 12.2, 18c). The Terminal Release of each branch receives the full support cycle: **Premier Support** for the initial years, followed by paid **Extended Support**, and finally **Market-Driven Support** on request. Oracle 19c, the Terminal Release of the 12.2 branch, has Premier Support through 2027 and Market-Driven Support through 2032.

Intermediate releases within the same branch (e.g., 18c) carry shorter support windows and do not qualify for the extended cycle.

## When to use it

The Terminal Release is the natural upgrade target for projects with a multi-year horizon: it provides code stability, regular security patches, and enough runway to plan the next migration without time pressure. In regulated industries — such as financial services — support predictability is a contractual and compliance requirement, not an operational preference.

Choosing an intermediate release over the Terminal Release means accepting a narrower support window, with the risk of having to plan a second upgrade within a short timeframe.
