## 3. Pulizie / Modifiche applicate

- **Correzione bug tema Hugo**: scoperto che `layouts/partials/header/hybrid.html` era il file **realmente attivo** (non `basic.html` come indicato erroneamente dal prompt). Hugo 0.161 supporta retrocompatibilità `partials`↔`_partials` — la modifica al brand block è finita nel file corretto. Ripristinato `basic.html` allo stato originale dopo un tentativo sbagliato iniziale.
- **Contatore Know-How refactor**: la logica del prompt `sub $rolesCount 1` avrebbe mostrato "3 pilastri" (perché la pagina TL non esiste ancora tra le `.Pages` fino al Passo C). Sostituita con un range esplicito che esclude per path `technical-leader`, robusto anche dopo l'aggiunta della pagina profilo.
- **body padding-top calibrato** a fronte del feedback utente "le prime righe vengono coperte dall'header".
- **Restart LaunchAgent Hugo**: dopo ~40 min di CPU cumulata su tanti rebuild consecutivi, il processo (PID 1742) era "impantanato" (timeout casuali). Kill via `SIGTERM`, LaunchAgent ha auto-rispawnato (nuovo PID 62892). Le pagine sono tornate a rispondere in ~30ms.

```bash
HTML=/tmp/cv-technical-leader.html

  --metadata pagetitle="Ivan Luminaria — Technical Leader CV" -o "$HTML"
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-pdf-header-footer \
  --print-to-pdf="$PWD/$OUT" "file://$HTML"
python3 -c "import re; b=open('$OUT','rb').read(); \
  print('pagine:', len(re.findall(rb'/Type\\s*/Page(?!s)', b)))"
```

Criterio di accettazione: **esattamente 2 pagine**, con la seconda piena almeno a metà.
